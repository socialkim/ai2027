# AI 2027 독자 실습실

『AI 2027 트렌드&활용백과』 독자 실습 페이지입니다. 깃허브 페이지로 공개합니다.

- 첫 화면: https://socialkim.github.io/ai2027/
- 프롬프트(활용 2장): https://socialkim.github.io/ai2027/prompt/ — 책 QR은 `/prompt/#builder`

## 공개하는 법 (한 번만)
1. 깃허브에서 **공개(Public)** 저장소 `ai2027`을 만들고 이 폴더의 파일을 그대로 올린다.
2. 저장소 Settings → Pages → Branch: `main` / `/(root)` → Save. 1~2분 뒤 위 주소가 열린다.

## 고치는 법
- 예시·문구는 `prompt/index.html` 맨 아래 `<script>`의 첫 부분("고칠 곳은 여기 한 군데")에 모여 있다.
- 방문 수: `GOATCOUNTER = ""` 따옴표 안에 고트카운터 계정 이름을 넣는다(두 파일 모두).
- '챗GPT에서 열기'·'클로드에서 열기'가 안 되면 `OPENERS`에서 `on: false`로 끈다.

## 바꾸면 안 되는 것 (책에 인쇄됨)
계정 이름 `socialkim`, 저장소 이름 `ai2027`, 폴더 이름 `prompt`, 위치 표시 `#builder` `#order` `#limits` `#aba` `#meta` `#week`.
